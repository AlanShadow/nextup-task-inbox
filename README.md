# NextUp 任务收件箱

把你主动从微信转发的消息和附件整理成任务。

## 下载 Windows 预览版

- [下载安装包 v1.1.6.5（Windows x64）](https://github.com/AlanShadow/nextup-task-inbox/releases/download/v1.1.6.5-beta/NextUp-TaskInbox-v1.1.6.5-win-x64-beta.zip)
- [查看发布说明与 SHA-256 校验文件](https://github.com/AlanShadow/nextup-task-inbox/releases/tag/v1.1.6.5-beta)

下载并解压全部文件，然后双击 `Install-NextUp.cmd`。首次安装需要确认管理员授权与自签名测试证书信任。详情见发布页。

## 从微信转为任务

在 Windows 微信中选中消息和附件，点击「逐条转发」→「其他应用」→「NextUp 任务收件箱」。核对工作内容和截止时间后，点击「确认并加入任务」。
